# Pre-0.1 API Freeze Items Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settle the four API questions the user decided on 2026-10-30, before 0.1 freezes the rza1 crates:
1. the USB endpoints' fields go private;
2. `rza1h` ships as experimental;
3. every rza1 crate is documented nightly-only;
4. the ring DMA descriptors become caller-lent, like the rings.

**Architecture:**
- **Endpoints:** `Rusb1EndpointIn`/`Rusb1EndpointOut` keep `port`, `pipe` and `info` private. `pipe()` is the one accessor; `info` comes through embassy-usb-driver's `Endpoint::info()`.
- **`rza1h`:** gets "experimental" docs, and its QEMU test build compiles, with pin-dependent tests gated to `rza1l`.
- **Toolchain:** each crate's README and crate docs say a nightly toolchain is required.
- **Descriptors:** a public `ring_buffer::RingDesc`, one 32-byte-aligned link descriptor with a `const NEW`, is lent as a checked `RingDescs<'d>` table in `RingBuf`. `RingDma::start` writes the caller's table. The private 8 KiB `RING_DESC` static goes.

**Tech Stack:** Rust (nightly), rza1-hal QEMU tests (`scratchpad/ht.sh`), deluge-bsp tests (`scratchpad/bt.sh`), the bench (demo-firmware audio; DelugeFirmware build).

**Spec:** none; these are the user's decisions of 2026-10-30, recorded in the conversation. They follow the pre-0.1 pass spec (`docs/superpowers/specs/2026-10-21-rza1-hal-pre-release-api-design.md`): caller-lent audio rings (decision 2) and "fixing these after a 0.1 publish would mean semver breaks".

## Global Constraints

- The layering rule (nothing under `rza1/` names the Deluge in code) and every check in `rza1/tools/test.sh` and `verify.sh` stay green.
- **`RingDesc`:**
  - It is exactly one 8-word link descriptor, `#[repr(C, align(32))]`, so one DMAC descriptor never shares a cache line with other data.
  - A table must hold at least `blocks` descriptors (blocks stay 2–16).
  - It must lie in memory the DMAC reaches through the uncached mirror: the same check as `dma_buf::UncachedMut::new`, failing with `NotUncached`.
- No SD writes on the bench (memory: sd-card-write-confirmation). The audio bench needs no card.
- Nothing is pushed.
- DelugeFirmware is affected only through `deluge-bsp`'s audio rings, which `deluge-bsp` builds itself, so DelugeFirmware needs no code change, only a build through `local-sdk.toml`.

## Review Focus

1. **A descriptor table shorter than `blocks`, or not DMA-reachable** (a stack array, cached-only memory).
   - Expected: a `NotUncached` error at `RingDescs::new` for the memory, and a clear panic at ring start for the length, as `blocks` is checked today.
   - Tests: `a_descriptor_table_outside_dma_memory_is_refused` and `a_short_descriptor_table_is_refused` (Task 4).
2. **Two rings sharing one table.**
   - Expected: impossible. `RingDescs<'d>` holds `&'d mut [RingDesc]`, so the borrow checker refuses it.
   - Test: none needed. The type is the guarantee; the review confirms no `Copy`/`Clone` on `RingDescs`.
3. **Descriptors through the cached alias.**
   - Failure: the DMAC reads stale descriptors.
   - Expected: written through the uncached alias, as today.
   - Test: `ring_descriptors_live_in_the_lent_table` asserts that the writes land at the lent table's uncached-alias addresses (Task 4).
4. **`rza1h` QEMU tests still not building.**
   - Expected: `cargo test --features rza1h --lib` builds and passes, and `test.sh` runs it.
   - Test: that run in `test.sh` (Task 2).
5. **Firmware audio after the descriptor move.**
   - Expected: unchanged.
   - Test: the bench in Task 4 (demo-firmware: `speaker-test` S24 and S16 play; `arecord` 3 s is exactly 793,844 and 529,244 bytes), and DelugeFirmware's `./dbt build` links.

### Task 4: Ring DMA descriptors lent by the caller

**Files:**
- Modify:
  - `rza1/rza1-hal/src/dmac/ring.rs` (`LinkDesc` → public `RingDesc`; `RING_DESC` static removed; `RingDma::start` takes the table);
  - `rza1/rza1-hal/src/ring_buffer.rs` (`RingBuf` gains `descs`; the `RingDescs` type);
  - `rza1/rza1-hal/src/ssi.rs`, `rza1/rza1-hal/src/scux.rs` (pass `descs` through);
  - their tests;
  - `crates/deluge-bsp/src/{audio.rs, scux_src_path.rs, scux_usb_tx_path.rs}` (static tables, lent);
  - `rza1/rza1-hal/README.md`, `CHANGELOG.md`.

**Interfaces:**
- Produces:
  - `#[repr(C, align(32))] pub struct RingDesc([u32; 8]);` with `pub const NEW: RingDesc` (zeroed), re-exported as `rza1_hal::ring_buffer::RingDesc`.
    - Doc: one DMAC link descriptor; a ring of n blocks needs n of them in DMA-reachable memory, written by the HAL through the uncached alias.
  - `pub struct RingDescs<'d>(&'d mut [RingDesc]);`, not `Copy`/`Clone`.
    - `pub fn new(descs: &'d mut [RingDesc]) -> Result<Self, NotUncached>` applies `dma_buf`'s check to the table's byte range.
    - `pub fn len(&self) -> usize`.
  - `RingBuf` gains `pub descs: RingDescs<'d>`.
  - `RingDma::start(dma, buf, descs: RingDescs<'d>, blocks, …)`:
    - writes `descs[0..blocks]` (uncached alias, as today);
    - panics as today if `blocks` is outside 2–16, and also if `descs.len() < blocks`: "dmac ring: {} blocks but {} descriptors";
    - holds the table for `'d`.
  - deluge-bsp: one `static mut` table per ring, sized to its block count (SSI TX/RX, SCUX FFD 8, FFU 16), each lent with `RingDescs::new(unsafe { &mut *addr_of_mut!(..) }).unwrap()`, next to its ring buffer.
- [ ] **Step 1: Write the failing tests** (rza1-hal; the existing `ring_buffer` and `dmac::ring` fixtures):
  - `ring_descriptors_live_in_the_lent_table`: start a 4-block ring with a leaked `[RingDesc::NEW; 4]`. Its words, read through the uncached alias, hold the header (`0b1101`), the per-block addresses and the self-link chain that `dmac::ring`'s existing descriptor test checks today, at the lent table's addresses.
  - `a_short_descriptor_table_is_refused`: a 4-block ring with a 3-descriptor table panics, `#[should_panic(expected = "4 blocks but 3 descriptors")]`.
  - `a_descriptor_table_outside_dma_memory_is_refused`: `RingDescs::new` on a table at an address outside `memmap::AREAS` returns `Err(NotUncached)`. Build that table the way `dma_buf`'s own refusal test does.

  Expected: FAIL to compile (no `RingDesc`).
- [ ] **Step 3: Implement** as in Interfaces. Update the existing ring, ssi and scux tests to lend tables, and deluge-bsp's three files.
- [ ] **Step 4: Verify**
